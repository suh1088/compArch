CTRL.v - 강의자료

jal - J-형식(J-type) 명령어로, PC 값을 변경하는 동시에 레지스터 파일(Register File)에 값을 써야 하는 복합적인 동작을 수행합니다.
=> 기존 J 명령어에서 r31 = pc; 만 추가된 형태. 
	PC+4 값을 레지스터 write data 에 넘기고, 
	ra레지스터 3:1 MUX에 상수값으로 입력
	MUX 추가

jr - R-형식(R-type) 명령어이지만, 일반적인 산술 연산과는 달리 ALU를 거치지 않거나 통과만 한 뒤 곧바로 PC를 업데이트합니다.
=> 기존 J 주소와 레지스터 값 둘 중 하나를 MUX를 통해 선택하고, 
	선택은 컨트롤 유닛 출력값 JR 하나 추가
